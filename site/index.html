SV2 DiffMod Spec

Status is draft. Spec version is 1.

What File Header Body Build Profiles

What it is

This spec defines the DiffMod form for Source 2 Panorama changes.

A DiffMod edits decompiled game sources.

A builder turns a DiffMod into a VPK.

Authors merge DiffMods with plain diff tools.

File form

A DiffMod is a UTF-8 text file with LF line ends.

Name DiffMod files with the .patch suffix.

Keep one DiffMod per file.

Header

The header holds zero or more lines at the top of the file.

Each header line starts with #.

The keys are spec, title, game, game-build, and decompiler.

Builders ignore unknown # lines.

Builders treat them as comments.

# spec: 1
# game: deadlock
# decompiler: source2viewer-cli 20.1
# title: Always show ability suggestions
--- a/panorama/styles/hud_ability_icon.css
+++ b/panorama/styles/hud_ability_icon.css

Body

The body is a unified diff.

The body MUST apply clean with git apply -p1.

Paths MUST use a/ and b/ prefixes.

Paths MUST stay relative to the VPK root.

New files MUST use --- /dev/null plus +++ b/<path>.

Version 1 forbids renames.

Version 1 forbids deletes.

Build

Decompile each target from the game VPKs.

Apply DiffMods in order.

If two DiffMods touch the same hunk, fail the build.

Compile each result with the game resourcecompiler.

Pack compiled outputs plus raw files into one VPK.

The builder MUST record the game build ID from steam.inf.

The builder MUST record the decompiler name and version.

The builder MUST record the spec version.

Profiles

Each game needs a profile.

Deadlock is the reference profile.

Other titles stay draft until a build test passes.
